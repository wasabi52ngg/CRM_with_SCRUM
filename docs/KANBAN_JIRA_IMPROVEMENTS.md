# Предложение: Продвинутая доска в стиле Jira

## Текущее состояние
- 4 колонки (К выполнению → В работе → К проверке → Готово)
- Drag & drop карточек
- Боковая панель с чекпоинтами и чатом
- Базовая информация на карточке: тип, важность, исполнитель, дедлайн

---

## 1. Карточки задач (расширенные)

### 1.1 Визуальные улучшения
- **Цветовая индикация** — цветная полоска слева по типу задачи (Фронтенд/Бэкенд/…) или по приоритету
- **Аватар исполнителя** — мини-фото вместо текста
- **Метки (labels)** — теги: «срочно», «баг», «фича», «блокер»
- **Подзадачи** — прогресс-бар (3/5 выполнено) на карточке
- **Вложения** — иконка и счётчик вложений
- **Комментарии** — счётчик непрочитанных комментариев

### 1.2 Быстрые действия на карточке
- **Клик** — открыть детали (как сейчас)
- **Двойной клик** — быстрое редактирование названия inline
- **Контекстное меню (правый клик)** — дублировать, переместить в спринт, изменить приоритет, удалить
- **Hover** — показать кнопки: изменить исполнителя, изменить дедлайн

---

## 2. Колонки

### 2.1 Гибкие колонки
- **Настраиваемые статусы** — админ проекта задаёт колонки (не только 4 фиксированных)
- **WIP-лимиты** — ограничение числа карточек в колонке (например, «В работе» макс. 3)
- **Счётчики** — количество карточек в заголовке колонки
- **Сворачивание колонок** — скрыть редко используемые

### 2.2 Действия в колонке
- **«+ Создать задачу»** — кнопка внизу каждой колонки, создаёт задачу сразу в этом статусе
- **Фильтр по колонке** — быстрый фильтр карточек внутри колонки

---

## 3. Боковая панель задачи (детальный просмотр)

### 3.1 Структура как в Jira
- **Вкладки**: Описание | Чекпоинты | Комментарии/Чат | Активность | Вложения
- **Правая колонка**: Исполнитель, Постановщик, Дедлайн, Важность, Метки, Связанные задачи
- **Редактирование полей** — клик по значению → inline-редактирование (без перехода на другую страницу)

### 3.2 Описание
- **Rich-text редактор** — Markdown или WYSIWYG (заголовки, списки, код)
- **Шаблоны описания** — для типовых задач (баг-репорт, фича и т.д.)

### 3.3 Чекпоинты (улучшения)
- Inline-добавление (реализовано)
- **Drag & drop** для изменения порядка
- **Подзадачи с процентами** — отметка «выполнено» влияет на общий прогресс задачи
- **Чекпоинты из шаблона** — при создании задачи по типу подставлять стандартный чеклист

### 3.4 Комментарии и активность
- **Комментарии с @упоминаниями** — уведомление пользователя
- **Лента активности** — кто что изменил и когда (статус, исполнитель, описание)
- **Реакции на комментарии** — эмодзи

### 3.5 Вложения
- **Загрузка файлов** — drag & drop в панель
- **Превью** — изображения, PDF
- **Связь с задачей** — файл привязан к задаче

---

## 4. Создание и редактирование задач

### 4.1 Модальное окно создания (как в Jira)
- **Быстрое создание** — поле «Создать задачу» в шапке доски, по Enter открывается модалка
- **Модалка с полями**: Название, Описание, Тип, Исполнитель, Дедлайн, Важность, Метки, Чекпоинты (опционально)
- **Создание из шаблона** — выбор типа задачи подставляет дефолтные чекпоинты

### 4.2 Редактирование
- **Inline на доске** — двойной клик по названию
- **Полное редактирование** — в боковой панели, все поля редактируемые
- **История изменений** — кто и когда менял каждое поле

---

## 5. Фильтры и представления

### 5.1 Фильтры
- **По исполнителю** — мои задачи / задачи Ивана
- **По типу** — только баги, только фронтенд
- **По меткам** — срочно, блокер
- **По дате** — просроченные, на эту неделю
- **Сохранённые фильтры** — «Мои открытые», «Блокеры»

### 5.2 Представления
- **Канбан** (текущее) — колонки по статусу
- **Список (List)** — таблица с сортировкой по любому полю
- **Календарь** — задачи по дедлайнам
- **Roadmap** — временная шкала, Gantt-подобный вид
- **Backlog** — приоритизированный список (для спринтов)

---

## 6. Спринты и Agile

### 6.1 Спринты
- **Создание спринта** — набор задач, даты начала/окончания
- **Доска спринта** — только задачи текущего спринта
- **Burndown-чарт** — график оставшейся работы
- **Velocity** — скорость команды по спринтам

### 6.2 Backlog
- **Приоритизация** — drag & drop для изменения порядка
- **Добавление в спринт** — перетащить из бэклога в спринт
- **Оценка** — story points при планировании

---

## 7. Уведомления и интеграции

### 7.1 Уведомления
- **Назначение** — уведомление исполнителю
- **Упоминание в комментарии** — @username
- **Изменение статуса** — опционально постановщику
- **Просрочка** — напоминание за N дней до дедлайна

### 7.2 Интеграции
- **Git** — связь коммитов с задачами (ключ задачи в сообщении коммита)
- **Email** — создание комментария по email
- **Webhooks** — события (создание, смена статуса) для внешних систем

---

## 8. UX и производительность

### 8.1 Навигация
- **Горячие клавиши** — `c` создать, `?` справка, `Esc` закрыть панель
- **Breadcrumbs** — Проект → Доска → Задача PROJ-123
- **Поиск** — глобальный поиск по задачам (название, описание, ключ)

### 8.2 Производительность
- **Виртуализация** — при 100+ карточках рендерить только видимые
- **Оптимистичные обновления** — UI обновляется до ответа сервера
- **Real-time** — WebSocket для синхронизации при работе нескольких пользователей

### 8.3 Адаптивность
- **Мобильная версия** — упрощённый вид, свайп между колонками
- **Компактный режим** — меньше карточек на экране, больше колонок

## Технические рекомендации

- **Frontend**: рассмотреть React/Vue для сложных интерактивных частей (drag & drop, real-time)
- **State**: централизованное состояние (Zustand, Pinia) для фильтров, открытых панелей
- **API**: REST + WebSocket для live-обновлений
- **БД**: индексы по статусу, исполнителю, проекту для быстрых фильтров
