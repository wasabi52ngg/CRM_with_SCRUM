# Техническое задание

**Тема:** 
Разработка информационной системы "СИСТЕМА УПРАВЛЕНИЯ ПРОЕКТАМИ В IT-КОМПАНИИ"

**Цель:**
Повышение эффективности управления проектами в IT-компании, автоматизация процессов планирования, контроля выполнения задач и взаимодействия между участниками проекта

**Программно-аппаратные инструменты**
• **Платформа:** Django 5.2.7 (Python)
• **Интерфейс:** HTML5, CSS3, JavaScript
• **СУБД:** SQLite3 (разработка), PostgreSQL (продакшн)

**Задача проекта:**
1. Изучить специфику управления IT-проектами, определить функциональные возможности системы управления проектами и разработать структуру системы на основе методологий Agile и Scrum.
2. Реализовать удобный и интуитивно понятный веб-интерфейс для различных ролей пользователей (клиенты, менеджеры проектов, разработчики), а также обеспечить корректность и точность обработки данных.
3. Тестирование и внедрение информационной системы с целью оптимизации процессов управления проектами в IT-компании.

**Источник:**
Мазаков Е.Б. Информационные системы управления проектами: учебное пособие / Е.Б. Мазаков. – СПб: СПГУ, 2023. – 156 с.

**Критерии приёмки:**
1. Код структурирован, с комментариями.  
2. Наличие UML-диаграмм
3. Блок-схемы алгоритмов согласно ГОСТ 19.701-90 Единая система программной документации
4. Обработка ошибок и валидация пользовательского ввода.
5. Все перечисленные модули реализованы и работают корректно.  
6. Визуализация алгоритмов понятна и наглядна.  
7. Приложение не «падает» при корректном использовании.  
8. Пользовательский интерфейс интуитивно понятен.
9. Пояснительная записка разработана согласно ГОСТ 7.32 – 2017 «Отчет о научно-исследовательской работе»

**Общие требования к ИС:**
1. Размещение на GitHub или его аналоге.
2. Наличие GUI интерфейса.
3. Программа должна демонстрировать следующие виды работы с данными:
• Чтение (просмотр проектов, задач, пользователей)
• Ввод (создание новых проектов, задач, регистрация пользователей)
• Поиск (поиск проектов, задач, пользователей)
• Сортировка (сортировка задач по статусу, приоритету, исполнителю)
• Удаление (архивирование проектов, удаление задач)
• Импорт (импорт данных о проектах)
• Экспорт (экспорт отчетов по проектам)
• Генерация отчетов (отчеты по выполнению задач, загрузке разработчиков)
• Фильтрация данных (фильтрация задач по типу, статусу, исполнителю)
4. Программа должна демонстрировать организацию безопасного входа в систему:
• Регистрация пользователей с различными ролями
• Вход по паролю
• Шифрование паролей с использованием встроенных средств Django
• Контроль доступа на основе ролей (клиент, менеджер, разработчик)
5. Приложение должно быть покрыто тестами
6. К БД предъявляются следующие требования:
• Представлена логическая структуры данных (поля, отношения)
• Описан процесс нормализации данных до 3-ей формы
• Описано использование операторов SQL
• Для демонстрации в БД должно быть не менее 100 записей
7. В приложении к пояснительной записки ВКР должны присутствовать:
• Техническое задание (1 стр.)
• Инструкция по установке ИС (системному администратору) (1-2 стр.)
• Инструкцию пользователю по работе с системой, с сообщениями об ошибках и рекомендациями пользователю что делать (3-5 стр.)
• Документация на программный код (2-5 стр.)

## Функциональные требования

### Роли пользователей:
1. **Клиент** - подает заявки на проекты, отслеживает статус выполнения
2. **Менеджер проектов** - управляет заявками, создает проекты, назначает задачи разработчикам
3. **Разработчик** - просматривает назначенные задачи, обновляет статус выполнения

### Основные функции системы:
1. **Управление заявками клиентов:**
   - Публичная форма подачи заявки
   - Обработка заявок менеджерами
   - Отслеживание статуса заявки клиентом

2. **Управление проектами:**
   - Создание проектов на основе заявок
   - Управление жизненным циклом проекта
   - Архивирование завершенных проектов

3. **Управление задачами:**
   - Создание задач различных типов (фронтенд, бэкенд, DevOps, QA, Android, БД)
   - Назначение задач разработчикам
   - Отслеживание статуса выполнения (К выполнению, В работе, К проверке/QA, Готово)
   - Kanban-доска для визуализации задач

4. **Управление спринтами:**
   - Создание и управление спринтами
   - Планирование задач в спринтах
   - Отслеживание прогресса спринта

5. **Система комментариев:**
   - Комментирование задач
   - Обсуждение деталей выполнения

### Технические характеристики:
- **Backend:** Django 5.2.7
- **Frontend:** HTML5, CSS3, JavaScript
- **База данных:** SQLite3 (разработка), PostgreSQL (продакшн)
- **Архитектура:** MVC (Model-View-Controller)
- **Аутентификация:** Django Authentication Framework
- **Авторизация:** Role-based access control (RBAC)
